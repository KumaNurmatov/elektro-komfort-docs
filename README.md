# Электро Комфорт — инструменты

Два отдельных инструмента, оба работают прямо в браузере (Google Chrome):

* **`tu.html` — Генератор ТУ.** Рабочий проект (12 л.) и протокол ЭТЛ (2 л.) по данным техусловий, журнал выданных протоколов, погода, подпись, печать с последней страницы. **Закрыт кодом доступа**: в репозитории лежит только зашифрованная версия (AES-256-GCM, ключ из кода через PBKDF2), без кода данные заказчиков не прочитать. Код в репозиторий не попадает.
* **`schemes.html` — Редактор схем.** Ситуационные схемы: подложка, линии КЛ/ЛЭП/заборы, знаки, выноски, размеры, условные знаки, штамп, масштаб чертежа.

## Важно

* Журнал выданных протоколов хранится в браузере у каждого своё. Чтобы не задвоить номера, перед выдачей сверяйтесь друг с другом или обменивайтесь файлом «Скачать журнал» / «Загрузить журнал».
* «Запомнить на этом устройстве» хранит код в браузере. Чтобы выйти — очистить данные сайта в браузере.

## Исходники

* `src/generator/app.html`, `build_tu.py` — оболочка генератора и сборка (шаблоны листов и журнал берутся из локальной папки, в репозиторий не выкладываются);
* `src/schemes/template.html` — исходник редактора (шрифт ISOCPEUR вставляется вместо `__FONT__`);
* `src/lock.py`, `src/lock_template.html` — закрытие файла кодом: `TU_CODE=… python src/lock.py "Генератор ТУ.html" tu.html`.
